## Deploy to Vercel

### Option 1: Vercel Dashboard (Recommended)
1. Go to [vercel.com/new](https://vercel.com/new).
2. Select the repository **`swear1style-sketch/heritage-version`**.
3. Keep default settings (`buildCommand: null`, `outputDirectory: .`) and click **Deploy**.

### Option 2: Vercel CLI
```bash
npx vercel
```

## Local Development

Run with any local web server:

```bash
# Using Python 3
python3 -m http.server 8001

# Using Node / npx
npx serve .
```

Open [http://localhost:8001](http://localhost:8001) in your browser.

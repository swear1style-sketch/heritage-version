FAQ

Common questions.

Is GCC always the better long-term choice?

+

For companies planning a large, multi-function, permanent India presence, usually yes. For a narrower or shorter-term engineering need, an ODC may simply be the right-sized answer indefinitely.

Can we run an ODC and a GCC at the same time?

+

Some companies do — an ODC for a specific function while a separate GCC handles others. It's not the most common structure, but it isn't unusual either.
